# In-Struct Defaults Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every remaining struct default into the struct itself (as in-class member initializers) and delete `InputModule::input_default_params()` and `InputModule::input_default_precision()`, with bit-identical numerical output.

**Architecture:** Derived scalar defaults become in-class member initializers that reference earlier-declared members (C++ evaluates default member initializers in declaration order, so depended-on fields are reordered to come first). The photon-density helpers `Omega0gFromTcmb`/`TcmbFromOmega0g` move from `PhotonsSpecies` into `include/common.h` as `inline` free functions (bodies copied verbatim) to break the `photons.h`↔`background.h` include cycle that otherwise blocks the `Omega0_g` initializer. Array and string-path defaults become plain in-struct initializers; the four runtime `class_dir`-prefixed file paths get relative defaults plus a small `precision::ResolveDataPaths()` method. No struct constructors are added.

**Tech Stack:** C++17, Make (`make class`, `make test-photons`), Cython wrapper generated by `generate_wrapper.py` (run automatically by `pip install .`), pytest reference-comparison suite (`python/test_class.py`).

**Design doc:** `docs/superpowers/specs/2026-06-04-in-struct-defaults-design.md`

**Key invariant:** A default-configuration run must be **bit-identical** before and after every task. Each task rebuilds and diffs against a reference captured in Task 0.

- [ ] **Step 1: Add the free functions to `common.h`**

Insert immediately after the `precision` struct's closing `};` (currently line 1096), before the `#ifdef __cplusplus / extern "C"` block at line 1098:

```cpp

/** Photon density parameter from CMB temperature.
 *  Omega0_g = (4 sigma_B / c) T^4 / (3 c^2 1e10 h^2 / Mpc_over_m^2 / 8 pi G),
 *  with sigma_B = 2 pi^5 k_B^4 / (15 h_P^3 c^2). Single source of truth for the
 *  T_cmb <-> Omega0_g conversion. Free function (not a PhotonsSpecies method) so
 *  that background.h's default member initializer can call it without the
 *  photons.h <-> background.h include cycle. */
inline double Omega0gFromTcmb(double T_cmb, double h) {
  const double sigma_B = 2. * pow(_PI_, 5) * pow(_k_B_, 4) / 15. / pow(_h_P_, 3) / pow(_c_, 2);
  return (4. * sigma_B / _c_ * pow(T_cmb, 4.)) /
         (3. * _c_ * _c_ * 1.e10 * h * h / _Mpc_over_m_ / _Mpc_over_m_ / 8. / _PI_ / _G_);
}

/** Inverse of Omega0gFromTcmb. */
inline double TcmbFromOmega0g(double Omega0_g, double h) {
  const double sigma_B = 2. * pow(_PI_, 5) * pow(_k_B_, 4) / 15. / pow(_h_P_, 3) / pow(_c_, 2);
  return pow(Omega0_g *
                 (3. * _c_ * _c_ * 1.e10 * h * h / _Mpc_over_m_ / _Mpc_over_m_ / 8. / _PI_ / _G_) /
                 (4. * sigma_B / _c_),
             0.25);
}
```

## Notes for the implementer

- **Why no constructors:** default member initializers can reference earlier-declared members, so derived defaults are expressed inline once the depended-on field is declared first. This keeps the structs aggregate-friendly and avoids any risk to `generate_wrapper.py` (which only ever reads member-declaration lines).
- **Why `pow` is kept (not `constexpr`):** the readers call `Omega0gFromTcmb` on real runs; rewriting `pow(x,4.)` as `x*x*x*x` is not guaranteed bit-identical and would churn baselines for no functional gain.
- **Line numbers** are from the pre-change tree and will drift as you edit; re-`grep` if an anchor has moved.
- If the `defcheck.ini` diff is ever **not** `IDENTICAL`, stop and investigate before proceeding — the refactor is meant to be behavior-preserving, so a diff means a transcription error (e.g. a mistyped initializer or a missed reorder).
